## Overview

Plugin Alliance Shadow Hills Mastering Compressor emulates the dual-stage mastering compressor combining optical and discrete VCA stages for rich, musical mastering compression.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Plugin Alliance Shadow Hills Mastering Compressor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Dual Stage** | Optical first stage followed by discrete VCA second stage in series |
| **Transformer Options** | Steel, nickel, and iron transformer coloration modes |
| **Gain Reduction Meters** | VU-style meters show optical and VCA compression independently |
| **Mastering Calibration** | Gain structure optimized for mastering and stem bus use |
